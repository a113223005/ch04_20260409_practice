# 實作能力：MyStyle 自動折扣機金牌解答 (Skills Answer)

## 1. 基礎實作規劃 (人類好閱讀版)

本功能是讓 MyStyle 的 Agent 學會簡單的數學加減法：

### 我要填什麼？ (Input)

- **目前的商品總價**：買了多少錢的衣服？
- **有沒有加好友**：是 MyStyle 的 LINE 好友嗎？

### 數學計算邏輯 (Computing Logic)

- **好友禮**：只要有加好友，總額直接「減掉 $50」。
- **滿千折百**：金額每滿 $1000 元，額外「減去 $100」（可累計）。
- **範例步驟**：點買 $2500 元，且是好友。
  -   第一步：$2500 - $50 = $2450。
  -   第二步：$2450 滿兩個千，所以減 $200。
  -   最終結果：應付 **$2250** 元。
