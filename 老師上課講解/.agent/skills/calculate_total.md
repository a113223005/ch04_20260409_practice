# 實作能力：飲品金額總計運算 (Total Calculation)

## 1. 基礎實作規劃 (運算敘述：小白版)

本項功能讓天下茶屋的 Agent 學會正確的算術邏輯：

### 接收資訊內容 (Input)
* **飲品定價**：天下紅茶($40)、天下綠茶($35)、特調奶茶($55)。
* **加料費用**：珍珠(+$10)、椰果(+$5)、仙草(+$5)。
* **週年慶折扣**：全品項 8 折。

### 數學計算題目 (Logic)
* **計算公式**：`總金額 = (單價 x 數量 + 加料費) x 0.8`。
* **範例**：點 2 杯天下紅茶 ($40x2)，加上珍珠 ($10)。
  * 第一步：($80 + $10) = $90。
  * 第二步：$90 x 0.8 = $72。
