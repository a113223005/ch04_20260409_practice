# 功能引擎與數據處理：MyStyle 自動化算帳機金牌解答

## 1. 基礎實作規劃 (人類好閱讀版)

本項功能負責 App 系統中的結帳自動化與促銷折抵邏輯：

### 核心運算步驟 (Computing Steps)

1.  **好友身份過濾**。系統自動檢查資料庫中的好友標記。如果該 ID 的標記為 True，則系統從原始總金額中減掉 **$50**。
2.  **滿千折百疊加**。系統偵測處理後的剩餘金額。每當金額中偵測到一個 **$1000** 元的單位，則系統自動執行減免 **$100** 的運算（此項優惠不限次數，可累計疊加）。
3.  **案例解析**。假設購物車原價為 **$2500** 並具備好友身分。
    - 步驟 1：產出折抵好友禮後的餘額為 $2450。
    - 步驟 2：因餘額中包含兩個滿千單位，系統產出折扣額度為 **$200**。
    - 步驟 3：產出最終實付金額為 **$2250**。

## 2. 進階實作規格 (AI好理解版)

### API 數據映射定義 (Data Mapping)

| 輸入參數 (In_Params) | 規格定義 | 預期輸出 (Out_Final) |
| :--- | :--- | :--- |
| **cart_total** | 購物原始總金額 (Number) | **sub_total_1** (折抵完好友) |
| **friend_tag** | 會員身份標記 (Boolean) | **sub_total_2** (折抵滿千後) |
| **discount_logic** | 累進折抵係數 (1000:100) | **final_price** (應收金額) |
