# 業務規則：外送門檻與範圍限制 (Delivery Rule)

## 1. 基礎實作規劃 (人類好閱讀版)

本項規則旨在保護營運成本，規範 Agent 如何依據距離決定服務範圍：

### 邏輯觸發條件

- **超出範圍**：當外送距離超過 **5 公里** 時，系統應強行攔截。
- **加收運費**：當外送距離介於 **2 至 5 公里** 且總計金額未達 **$300** 時，系統應加收 $50 運費。
- **免運條件**：距離 **2 公里內** 無門檻限制。

### 回報文字建議

- 超出範圍時提示：「很抱歉！您的位址超出了我們 5 公里的服務半徑。」
- 加費提示：「您的距離需加收 $50 運費，建議您再多點購品項湊滿 $300 以享免運。」

---

## 2. 進階實作規格 (AI好理解版)

為確保邏輯精確性，定義下列判斷矩陣：

### 邏輯決策表 (Decision Table)

| 距離標籤 (distance) | 訂單總額 (total) | 執行動作 | 指令碼 (Action_Code) |
| :--- | :--- | :--- | :--- |
| **> 5km** | 不限 | 強制攔截 | `REFUSE_SERVICE` |
| **2-5km** | < $300 | 疊加 $50 | `ADD_FEE_50` |
| **2-5km** | >= $300 | 允許通行 | `ALLOW_FREE` |
| **< 2km** | 不限 | 允許通行 | `ALLOW_FREE` |
