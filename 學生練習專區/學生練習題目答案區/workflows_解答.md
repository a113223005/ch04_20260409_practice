# 用戶旅程與執行流程：MyStyle 智慧結帳 SOP 金牌解答

## 1. 基礎實作規劃 (人類好閱讀版)

本流程規定了系統在接收到結帳請求時，於後端應執行的邏輯檢查點：

### 核心執行站點 (Workflow Stations)

1.  **第一站：購物車快照 (Cart Snapshot)**。系統自動同步品項清單，並標記其中的顏色、售價與促銷標籤。
2.  **第二站：業務規則校驗 (Policy Check)**。如果清單內存在白色衣物，系統則在下一步導引中由後端觸發告知退換貨限制。
3.  **第三站：促銷引擎套用 (Promotion Engine)**。系統自動偵測 LINE 好友身分，並累計套用滿千折百之算法模組。
4.  **第四站：確認結算與跳轉 (Order Completion)**。產出最終應付金額，並導引顧客進行支付支付。

## 2. 進階實作規格 (AI好理解版)

### 系統執行狀態表 (State Transitions)

| 關鍵節點 (Task_Node) | 系統執行動作 | 預期輸出產物 |
| :--- | :--- | :--- |
| **Data_Fetch** | 抓取 UserID 與 Cart_ID 數據 | 用戶標籤清單 |
| **Logic_Gate** | 針對色標為 White 之品項觸發警語彈窗 | 規則檢查戳記 |
| **Engine_Call** | 發送原始金額至 Skills 模組運算 | 最終折扣淨價 |
| **Payment_Jump** | 清算購物車並跳轉支付頁面 | 訂單序號完成頁 |
