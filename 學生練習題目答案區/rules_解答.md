# 業務規則：MyStyle 退貨攔截金牌解答 (Return Rules Answer)

## 1. 基礎實作規劃 

本項目標是為了保護 MyStyle 的品質與衛生：

### 什麼品項不予退換？

*   **白色衣物**：凡是「白色 (White)」系列的衣服，結帳後一律不能退換。
*   **出清特價品**：凡是標註為「特價 (On Sale)」的促銷品，一律不能退。

### Agent 要做什麼？

*   **掃描檢查**：當檢測到白色衣服或特價品時，主動跳出提示。
*   **提示說明**：在確認視窗顯示：「白色衣服為了衛生是不退換的喔，要考慮清楚再買！」
