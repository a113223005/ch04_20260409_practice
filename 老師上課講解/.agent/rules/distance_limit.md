# 業務規則：產品外送服務限制 (Dintance Rules)

## 1.基礎實作規劃 (人類好閱讀版)
情境：天下茶屋要開放外送功能，但不同距離有不同規則：

距離超過 5 公里 → 拒絕服務
距離 2～5 公里，且訂單未滿 $300 → 加收 $50 運費
距離 2 公里內 → 免運費
任務：寫出這條規則的「基礎實作規劃」與「進階實作規格」（Decision Table）。

## 2. 進階實作規格 (AI好理解版)

### 外送服務距離限制

| 距離限制 (Input) | 訂單金額 (M) | 系統權限 (Status) | 系統反饋 (Message) |
| :--- | :--- | :---| :--- |
| **距離 > "5公里"** | 不限 | 拒絕服務 (Denied) | 提示：不好意思，因超過距離不提供外送服務。 |
| **距離 == "2~5公里", 且訂單未滿 $300 ** | 加收 $50 運費 | 提示：因外送距離較長加收50元外送費用。|
| **距離 < "2公里"** | 提供服務 (Allowed) | 無警告，正常顯示結帳按鈕 |
