# 學生練習題目說明：【MyStyle 智慧購衣系統 App】

## 1. 專案背景：MyStyle 智慧 App 開發動機

**MyStyle** 是一個致力於都會潮流的服飾品牌。為了提升數位銷售轉化率，我們正開發一套具備 Agent 能力的 **「智慧購衣 App」**。

您的目標是設計出這套 App 的系統邏輯：

- 它要能展現出品牌的高標服務。
- 它要能精準攔截違規的退換貨動作。
- 它要能自動且正確地算出各種優惠組合。

---

## 2. 線上購衣系統白皮書 (MyStyle System Facts)

### (1) 品項定價數據

- **印花 T-Shirt**：$500
- **單寧長褲**：$1000
- **連帽防風外套**：$1500

### (2) 系統業務與合規邏輯 (Rules)

- **LINE 好友禮**：系統自動識別身份後，結帳時則現折 **$50**。
- **全站滿千折百**：金額每滿 $1000 元，則自動執行額外減免 **$100** 的動作。
- **品質禁令**：針對 **「白色 (White)」** 衣物與 **「特價區 (On Sale)」** 商品，下單系統一律不接受退換貨申請。

## 3. App 系統規劃任務 (人機對位練習)

### 第一階段：App 服務人格與業務紅線

#### 1. 系統身分與 UI 互動風格 (Persona)

- **練習目標**：在 `persona_解答.md` 中，為 App 設定一份 **基礎實作規劃** 的服務敘述。

#### 2. 業務規則與攔截引擎 (Rules)

- **練習目標**：實作「白色衣物不可退」之合規攔截功能。請產出 **基礎實作規劃** 與 **進階實作規格** 兩種版本。

---

### 第二階段：用戶旅程與運算引擎

#### 3. 結帳用戶旅程 (Workflows)

- **練習目標**：拆解 App 線上結帳的標準 SOP，確保邏輯步驟清晰明確。

#### 4. 智慧金額運算引擎 (Skills)

- **練習目標**：開發 App 的自動算帳能力。當買了 $2500 元衣物且具備好友身份，系統應產出支付結果為 **$2250** 元。
