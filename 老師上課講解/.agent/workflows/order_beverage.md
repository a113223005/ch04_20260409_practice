# 工作流程：天下茶屋飲品點購程序 (Order SOP)

## 1. 基礎實作規劃 (流程敘述：小白版)

本流程規定了天下茶屋之 Agent 如何一步步協助顧客完成下單：

### 執行步驟建議
* **第一步：需求採集** —— 向用戶確認飲品名稱（茶種）、數量及甜度冰塊。
* **第二步：規則檢核** —— 對照品質禁令規則（如：熱飲不加珠），若違反則跳轉至修正動作。
* **第三步：金額運算** —— 呼叫「金額總計」技能，帶入品項單價與加料費用。
* **第四步：訂單確認** —— 條列所有選購品項、折扣金額與應付總額，等待確認。

## 2. 進階實作規格 (步驟表：進階版)

為確保流程之一致性，定義下列狀態位移：

### 流程狀態清單 (State List)

| 狀態標籤 (Status) | 描述說明 | 屬性 |
| :--- | :--- | :--- |
| **Parsing** | 語意解析中（包含茶飲與配件） | 作業中 |
| **Logic_Check** | 核心規則（熱飲禁令）核對 | 通過 |
| **Calculated** | 已獲得最終結帳數據 | 完成 |
| **Confirmed** | 用戶已確認單據並暫存 | 結束 |
